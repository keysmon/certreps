# AIP-C01 Coverage Map

Reviewed 2026-11-22 against the official AWS task outline. This optional map connects every task to examples in the active bank and written lessons. You can practice immediately without completing it.

## How to use the evidence

Each section lists the scope of its practice examples and links to lessons. The counts describe editorial mappings, not your mastery, actual exam frequency or proof that every subskill is fully covered. Several questions can support one task, and a question can support more than one task. Repeated high scores are not evidence of transfer to unfamiliar scenarios.

The bank now includes data-service selection, managed agent evaluation, model lifecycle and developer delivery, alongside the existing RAG, safety, identity and serving lessons. Detailed questions include canonical option reasoning and primary AWS sources.

## Try it

Choose one task and explain a scenario before opening feedback: the user goal, constraints, selected design, strongest rejected alternative and evidence that the system works. Change one constraint and decide whether the answer changes. Use a full mixed mock to test timing separately from targeted study.

## Check your reasoning

**Does a mapped question prove mastery of a task?** No. It provides a concrete practice opportunity. Review underlying lessons and use unfamiliar cases to test transfer.

**Does every named AWS service need the same number of questions?** No. Study decisions and interfaces within the task scope; examples and service availability change. Verify current documentation for version-dependent details.

**What remains beyond this map?** Hands-on execution, production scale, all SDK variants and independent difficulty calibration are not established by written content. In particular, vector-store sizing, sharding and hybrid/edge deployment need workload-specific study. The official guide remains the authority on scope.
